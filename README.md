# MAGD-150_GitHub_Project
The first file titled **Lab 7 Assignment** is the lab in the MAGD 150 course from March 18th that taught us how to use the following functions in p5.js: translate, scale, rotate, angleMode, push and pop, and print. The sketch depicts a _Retro Game_ with a graphic on a rectangular screen. Within the code, the print function is used to calculate a set amount of weight as if you were placed on the moon.  
The second file titled **Lab 8 Assignment** contains the lab from the first week in April that taught us how to load images and text into a p5.js using the preload and draw functions. We uploaded jpeg and transparent png files onto the sketch and used _Simple Web Server_ to check our work. For the text, we inserted text into the sketch, changing its position, font, stroke and fill, and its width and height.  
The third file titled **Lab Assignment 10** contains the files from April 15th where we learned how to utilize the p5.js libraries. For this assignment, we were required to use a _minimum_ of three unique functions or methods from the library we all respectively chose. I chose a color generator library, so I included all of the various color arrays the library is capable of generating.
